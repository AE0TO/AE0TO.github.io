# AE0TO — Holographic Ham Radio Command Center

## Quick publish (no coding)
1. Create a GitHub account and repository named `ae0to.github.io`.
2. Add the files in this repo using GitHub's web editor (Create new file → paste content → Commit).
3. In Settings → Pages, set Source to `main` branch and root `/`.
4. Wait a few minutes and open `https://<yourusername>.github.io/`.

## Edit site content
- **Change callsign/name/QTH or jukebox links:** Edit `assets/config.json`.
- **Add jukebox tracks:** Edit `assets/playlists.json` or add direct MP3 URLs to `assets/config.json`.
- **Update military bio:** Edit `content/military.md`.
- **Add images:** Upload to `assets/images/` and reference filenames in markdown.
